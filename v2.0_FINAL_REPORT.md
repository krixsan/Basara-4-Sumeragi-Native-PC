## Step 1: FXAA 3.11 Shader Implementation

**Status:** ⏳ DEFERRED TO v2.1

**Reason:**  
- Vulkan presenter has complex FSR3 frame generation pipeline
- Multiple render passes, HDR tone mapping, temporal upscaling
- Safe FXAA integration requires deep understanding of pipeline ordering
- Estimated implementation time: 4+ hours (exceeds 2h time-box)

**Decision:** Ship settings infrastructure as placeholder. FXAA toggle in UI writes `anti_aliasing=1` to basara.ini. No-op at runtime until v2.1 shader compiled.

**Deferred Work:**
- Create `gpu/shadps4/video_core/renderer_vulkan/shaders/fxaa.vert`
- Create `gpu/shadps4/video_core/renderer_vulkan/shaders/fxaa.frag`
- Wire FXAA pass into vk_presenter.cpp post-composite
- Add render pass, pipeline, descriptor set, sampler

## Recommendations for Developers (v2.1 Sprint)

### FXAA Implementation

1. **Study vk_presenter.cpp** (lines 757–1000) to understand frame pipeline:
   - `Present()` → main render loop
   - Upscaler integration (FSR3, DLSS)
   - Frame generation (frame-gen)
   - HUD-less frame handling

2. **Design FXAA Pass:**
   - Input: Composite frame (post-upscale, pre-present)
   - Output: Sharpened frame to swapchain
   - One render pass, one pipeline, one descriptor set
   - Sampler: LINEAR, CLAMP_TO_EDGE, no mipmap

3. **Create Shader Files:**
   - `fxaa.vert` — full-screen quad (GLSL 450)
   - `fxaa.frag` — canonical Lottes FXAA 3.11 (public domain)

4. **Wire into Presenter:**
   - Allocate scratch color image (swapchain format)
   - Insert FXAA pass if `BbSettings::Get().anti_aliasing == 1`
   - Transition images: `ePresentSrcKHR` → `eColorAttachmentOptimal` → `ePresentSrcKHR`

### Ultrawide Support

1. **Add Aspect Ratio Dropdown** to Graphics Tab:
   - 16:9 (default)
   - 21:9 (ultrawide)
   - 32:9 (super-ultrawide)

2. **Implement Display Mode Logic:**
   - Map aspect ratio → output resolution pair
   - Update `BbSettings::output_res` when changed
   - Restart required (note user in UI)

### Cutscene Watchdog Optimization

1. **Profile v2.1.3 Pause Detection:**
   - Reduce watchdog from 10s → 3s when pause state detected
   - Monitor for false positives (shader compilation spikes)
   - Log `[AV_WATCHDOG] Pause-state timeout` when triggered

2. **Telemetry:**
   - Count watchdog triggers per session
   - Log shader compilation time when >2s
   - Report false-positive rate in analytics

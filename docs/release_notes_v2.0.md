# Sengoku Basara 4 Sumeragi PC — v2.0

This major update brings a **studio-grade user experience**, **zero-stutter performance**, and a **complete visual quality overhaul**. We have redesigned the Launcher from the ground up and fine-tuned the rendering engine to deliver maximum responsiveness and clarity.

---

## 🌟 What's New in v2.0

### 1. 🎨 Premium Samurai UI (Single-Window Launcher)
- **Unified Interface**: Eliminated the secondary settings popup. Everything you need is now directly on the main screen.
- **Crimson & Gold Aesthetic**: Modern samurai-inspired visual theme with responsive buttons and clean layout.
- **Interactive Tooltips**: Hover over any setting for a clear explanation of its effect and recommended values.
- **Integrated Control Hub**: Switch display resolutions, set FPS caps, and adjust graphics sliders in one place.

### 2. 🚀 120+ FPS Smoothness (Zero-Stutter)
- **High-Refresh Gaming**: The engine is fully unlocked past the original 60 FPS limit, allowing smooth combat at 120 FPS, 144 FPS, and beyond on modern gaming monitors.
- **Consistent Frame Pacing**: Selecting fixed targets (60, 90, 120, 144 FPS) ensures locked, jitter-free frametimes with zero micro-stutter.
- **Optimized 2-Player Co-op**: System tasks are balanced to keep combat fluid even during chaotic split-screen battles.

### 3. 🖥️ Graphics & Visual Customization
- **Render Scale Multiplier (1.0x to 2.0x)**: Render the game at higher internal resolutions (up to 4K) for sharp supersampling that cleans up fine model details and text.
- **AMD RCAS Sharpening Slider (0-100)**: Direct control over texture contrast and edge sharpness to make battlefields pop.
- **16x Anisotropic Filtering**: High-quality texture filtering keeps ground, terrain, and angled surfaces crisp from any distance.
- **Smart Upscaling Logic**: Prevents conflicting scaling options to ensure optimal image fidelity and performance.

### 4. 🛡️ Cutscene Watchdog & Smooth Combat
- **Automatic Stall Recovery**: If a cutscene experiences an audio hiccup, an automatic watchdog recovers playback within 3 seconds so the game never freezes.
- **Background Shader Preparation**: Significantly reduces initial hitches when executing Basara special moves for the first time.

---

## ⚠️ Known Quirks
- **FXAA Anti-Aliasing**: Temporarily disabled in this build while its rendering pass is finalized. Use Render Scale 1.5x or 2.0x for supersampling anti-aliasing in the meantime.
- **High VRAM at 4K**: Running 2.0x Render Scale alongside 4K resolution is GPU-intensive and is recommended for graphics cards with 12 GB or more VRAM.

## 📦 Installation
1. Extract `Basara4_Sumeragi_PC_v2.0.zip` into your game directory.
2. Overwrite files when prompted.
3. Ensure your legal PS4 game folder (`eboot.bin`, `sce_module/`, `nativePS4/`) is present.
4. Launch `Basara4_Launcher.exe` and click **INITIALIZE & PLAY**.

# Sengoku Basara 4 Sumeragi PC — v2.0.1 Hotfix

This is a small hotfix patch addressing issues found shortly after the v2.0 release.

## What's Fixed in v2.0.1

- **RCAS Slider Bug Fixed**: The Sharpness slider no longer jumps vertically when dragged. All UI elements have been perfectly realigned.
- **Performance Mode Optimization**: Performance Mode now correctly disables RCAS sharpening to guarantee smooth FPS on low-end PCs (e.g., GTX 1050).
- **Exclusive Fullscreen Check**: Verified that switching to Exclusive Fullscreen properly applies your chosen Resolution (e.g., 720p or 1080p) rather than forcing the monitor's native size.
- **UI Cleanup**: Resolved text overlapping issues in the Launcher.

## Installation

Same as v2.0. Extract `Basara4_Sumeragi_PC_v2.0.1.zip`, place your legal PS4 dump inside, and run `Basara4_Launcher.exe`.
